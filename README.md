# Z.A.T.O. — исправление пиксельного тумана v0.9.1

Замените два файла в проекте Godot 4:

- `scripts/effects/fog_of_war.gd`
- `shaders/pixel_fog.gdshader`

`scenes/effects/fog_of_war.tscn` менять не нужно. `TileMapLayer` не изменяются.

## Что исправлено

1. Тени и края обзора теперь привязаны **к мировой пиксельной сетке**, а не к экрану. Перемещение камеры больше не заставляет сетку темноты «ползти» по декорациям.
2. Пересчёт лучей согласован с обновлением точки обзора: при движении лучи пересчитываются при смене мировой пиксельной ячейки, а стоя на месте — раз в 0.12 секунды.
3. Реальные прямоугольные коллизии стен учитываются **до задней грани** (с ограничением 48 px), чтобы стены оставались видимыми, но пространство за ними скрывалось.
4. Убрано сильное плавное затемнение перед преградами, из-за которого прежде даже видимые стены пропадали.
5. Для читаемого углового силуэта используется 384 луча вместо 192.

## Параметры Inspector

- `Pixel Size = 4`: размер ступеней в **мировых** пикселях.
- `Wall Reveal Depth = 48`: до какой глубины видна стена от её передней грани. Подходит для тайлов 48×48.
- `Wall Back Margin = 1`: минимальная тёмная полоса у задней стороны стены.
- `Visible Area Dim = 0.045`: легкое затемнение видимой области; установите 0 для полной яркости.
- `Outer Fade Width = 28`: ступенчатое затухание только у **внешнего края радиуса** при отсутствии препятствий.
- `Ray Update Seconds = 0.12`: обновление лучей, пока игрок стоит на месте (открытие двери и т.п.).

## Примечания

- Поскольку стены определяются **по физическим коллизиям**, у стены должна быть коллизия на маске 4. Если есть декоративные стены без коллизий, они не перекроют обзор.
- Часть стены видна только при прямой видимости до соответствующего участка её коллайдера; за углы и в другие комнаты без линии обзора заглянуть нельзя.
- В проекте камера без поворота; расчёт экранного сдвига рассчитан на обычную не вращающуюся `Camera2D`.
- При изменении структуры стен во время игры убедитесь, что перестроены их коллизии.
- Godot в доступной среде не установлен; скрипт требует проверки непосредственно в редакторе.
