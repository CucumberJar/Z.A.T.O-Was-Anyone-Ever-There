# Z.A.T.O.: Was Anyone Ever There? — v0.4.4

**Engine:** Godot 4.7.2 (Compatibility), GDScript  
**Setting:** Варкута-3, 1987 · научно-исследовательский институт  
**Main scene:** `res://scenes/main_indoor.tscn`

## Что изменено

- Игровая локация полностью переложена на оригинальную сетку **48×48 px** по предоставленным наборам **White Bunker** и **Tunnels**. Никакого размыва при изменении размера тайлов.
- Архитектура оформлена отдельными слоями `TileMapLayer`: `FloorTiles`, `CeilingTiles`, `WallTiles`, `EquipmentTiles`.
- Композиции из нескольких тайлов (серверный шкаф, лабораторный пульт, архивные шкафы, генератор, столы) размещаются **целиком**, с правильным порядком элементов.
- Сценарные помещения соединены обходными коридорами. Сохранены интерактивные объекты, предметы, ночной преследователь, оружие и базовые фазы игрового цикла.
- Игрок **начинает внутри лифта**. Подойдите к его дверям и нажмите `E`, чтобы выйти. До этого вход в комплекс заблокирован физическим препятствием.
- Спрайт сотрудника СБ остаётся 32×64 пикселя по кадру, отображается целочисленно-пиксельным масштабированием (в игре ×1.5).

## Запуск

1. Распакуйте папку проекта.
2. В Godot 4.7.2 выберите `Import` и укажите `project.godot`.
3. Нажмите **F5**.
4. **WASD** — перемещение, **E** — взаимодействие, **Space** — рывок, **ЛКМ** — выстрел (когда доступен пистолет).

## Первый маршрут

1. Начало — кабина лифта, диалог с наставником через сообщение.
2. Подойдите к двери в правой части кабины и нажмите **E**, она откроется.
3. Через коридоры доберитесь до приёмной и красного стола.
4. Затем посетите вычислительный зал и взаимодействуйте с суперкомпьютером: запуск аварии на 99,99 %.
5. Собирайте ресурсы, прячьтесь и готовьте кабинет к выживанию ночью.

## Редактирование карты — исправлено в v0.4.4

**Карта теперь записана прямо в `scenes/indoor_institute.tscn` и доступна для рисования в Godot.**
Выбирайте нужный `TileMapLayer`, рисуйте, сохраняйте Ctrl+S, затем запускайте F5.
`indoor_map.gd` больше не очищает тайлы и не читает `indoor_layout.txt`; он только строит коллизии и A* из сохранённых слоёв.
Подробности: `docs/LEVEL_CONSTRUCTION.md`.

## Проверка и ограничения

Проверены размеры текстур, относительные пути ресурсов, синтаксические связи в сценах, связность карты и доступность сюжетных точек с учётом коллизий мебели. **Запуск Godot в текущем окружении недоступен**, поэтому графические/скриптовые ошибки, если они обнаружатся при импорте, необходимо проверить в самом движке.

### Права на ассеты

Приложенные пользователем тайлсеты подписаны как материалы из **Fear & Hunger 2: Termina**. Использование в данном проекте следует считать **частным прототипированием**. Для публичной публикации на itch.io требуется разрешение правообладателей или замена всех соответствующих графических ресурсов на собственные/лицензированные. Проект не заявляется как готовый к коммерческому распространению с этими текстурами.


## UI v0.6.0 — досье, пауза, связь

- Главная сцена теперь `scenes/ui/start_menu.tscn`.
- Меню в виде утверждённой папки с материалами, кнопки на иллюстрации интерактивны.
- `Esc` — меню паузы на фоне раскрытого личного дела: продолжить, сохранить, загрузить, настройки, в меню.
- HUD показывает только здоровье, патроны, фазу/время и короткую задачу.
- Диалоговое окно появляется при сообщениях и пропадает после заданного времени.
- Графика UI: `assets/ui/`; логика: `scripts/ui/`; сцены: `scenes/ui/`.
- Один локальный слот сохранения `user://zato_slot1.json` (черновой механизм; положение врага при загрузке сбрасывается к точке появления).
- Превью: `docs/ui_*preview.png`. Они не являются записью работающего Godot.

Для сохранения собственных правок карты используйте патч `ZATO_UI_v0.6.0_Patch.zip`, а не заменяйте всю папку проекта данным архивом.
