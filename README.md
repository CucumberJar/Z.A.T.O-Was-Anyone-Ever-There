# Z.A.T.O. v0.7.0 — мини-игра запуска «Контура»

Совместимо с текущим `main` GitHub-репозитория на 24 октября 2026. Изменяет только `scripts/main_indoor.gd` и добавляет две сцены/скрипта. Сцены карты, персонажа, HUD и TileMapLayer не трогает.

## Установка (Windows PowerShell)

Распаковать ZIP в отдельную папку. Из корня игры:

```powershell
python "D:\\ПУТЬ_К_ПАТЧУ\\install_supercomputer.py" .
```

Или положить `install_supercomputer.py`, `scenes/minigames` и `scripts/minigames` в корень проекта, затем:

```powershell
python .\install_supercomputer.py .
```

При изменении игрового скрипта создаётся `scripts/main_indoor.gd.pre-supercomputer.bak`. Повторное применение не добавляет дубликатов.

## Как проверить

1. Запустить игру через F5. Начать в лифте, выйти с помощью E.
2. По желанию подойти к красному столу и прочесть инструкцию 12-Б.
3. В вычислительном зале подойти к суперкомпьютеру и нажать E.
4. Три канала нужно привести к норме кнопками «−» и «+». Диагностика показывает, в какую сторону двигаться. Правильные значения: 04, 07, 02.
5. При прочтении инструкции будет явная подсказка выключить обратную связь. Без неё можно догадаться самостоятельно.
6. После калибровки нажать «ПУСК УСТАНОВКИ». В течение нескольких секунд счётчик доходит до 99,99%, затем экран становится синим.
7. Подтвердить ошибку кнопкой или Enter. Вернувшись в игру, увидеть аварийную фазу PANIC, красное освещение и таймер сбора ресурсов.

До пуска можно закрыть интерфейс клавишей Esc. После начала пуска установка уже не принимает отмену. В паузу по Esc во время мини-игры нельзя выйти, чтобы не открывались два перекрывающихся окна.

## Сюжетное поведение

- Обратная связь **включена**: `FATAL_FEEDBACK_LOOP`, ошибка оператора.
- Обратная связь **выключена**: `EXTERNAL_CODE_OVERRIDE`, КОД проигнорировал безопасную команду. Катастрофа всё равно происходит как часть истории.

Игровая фаза, здоровье, инвентарь, сохранения, UI, карта и коллизии остаются прежними. Это вертикальный срез, рассчитанный на браузерный Godot Compatibility; не создаёт новые ресурсоёмкие эффекты и не требует плагинов.

**Важно:** автоматическая проверка синтаксиса/ресурсов проведена; запуск в Godot 4.7.2 необходимо проверить локально, движок недоступен в среде сборки.
